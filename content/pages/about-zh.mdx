# 关于 DeepResearch.report

DeepResearch.report 是一个专注于深度研究报告的开放平台。我们的使命是让优质的研究报告更容易被发现和获取。

## 核心功能

### 1. 研究报告
我们收集并整理来自世界各地的高质量研究报告，涵盖人工智能、区块链、Web3、金融科技等前沿领域。所有报告都经过精心筛选和分类，确保内容的质量和价值。

### 2. 分类浏览
为了帮助用户更好地发现感兴趣的内容，我们建立了完善的分类系统。用户可以按主题、行业、发布时间等多个维度浏览和筛选报告。

### 3. 实时更新
我们会持续更新最新的研究报告。关注我们的 X（前身为 Twitter）账号 [@realShineHuang](https://x.com/realShineHuang) 可以第一时间获取更新通知。

## 为什么创建这个平台？

在当今信息爆炸的时代，找到真正有价值的深度研究报告并不容易。很多优质报告分散在各个角落，缺乏统一的发现和获取渠道。DeepResearch.report 正是为解决这个问题而生。

## 开放和免费

我们坚信知识应该是开放和共享的。因此，平台上的所有内容都是完全免费的。我们欢迎所有对深度研究感兴趣的人使用这个平台。

## 技术实现

DeepResearch.report 使用了现代化的技术栈构建：

- Next.js 14 - React 框架
- Tailwind CSS - 样式系统
- Contentlayer - 内容管理
- Vercel - 部署和托管

## 未来规划

我们将持续改进平台功能，计划添加：

- 更多研究领域的报告
- 高级搜索功能
- 个性化推荐
- 社区讨论功能
- 多语言支持

感谢你对 DeepResearch.report 的关注和支持！
